# 故障排查

## ChatGPT 连接器提示 No tools listed

检查：

1. 本地服务是否运行：`http://127.0.0.1:2091/health`
2. ngrok 是否运行。
3. 连接器 URL 是否以 `/mcp` 结尾。
4. 修改工具后是否点击 Refresh。
5. 终端是否有错误日志。

## 502 / 504

常见原因：

- ngrok 隧道关闭。
- 本地端口不是 2091。
- 服务绑定到了不可访问的 HOST。
- 公司网络代理拦截。

尝试：

```bash
curl http://127.0.0.1:2091/health
```

再打开 ngrok 的 Web 面板查看请求。

## ROOTS path does not exist

`.env` 里的目录不存在。Windows 建议写：

```env
ROOTS=D:/work/project
```

不要写错盘符，也不要用中文分号。

## Path is blocked by safety pattern

路径命中了 `DEFAULT_EXCLUDE_PATTERNS` 或 `EXTRA_EXCLUDE_PATTERNS`。

如果是误伤，优先通过 `EXTRA_EXCLUDE_PATTERNS` 调整业务目录，不建议删除 `.env`、密钥、token、数据库相关排除项。

## Write tools are disabled

需要开启：

```env
ALLOW_WRITE=1
```

修改已有文件还需要：

```env
ALLOW_OVERWRITE=1
```

修改 `.env` 后必须重启服务。

## File already exists

`write_file` 覆盖已有文件时，需要：

```json
{
  "overwrite": true
}
```

并且 `.env` 中：

```env
ALLOW_WRITE=1
ALLOW_OVERWRITE=1
```

## Refusing to read binary-looking file

该文件可能是二进制文件，或文本编码异常。这个连接器只用于文本项目文件，不建议放开二进制读取。

## MCP Inspector 连接失败

确认服务在运行，然后执行：

```bash
npx @modelcontextprotocol/inspector@latest --server-url http://localhost:2091/mcp --transport http
```

如果 Inspector 能连而 ChatGPT 不能连，问题通常在 ngrok HTTPS 地址或 ChatGPT 连接器配置。
