# 环境变量说明

所有运行配置都在 `.env`。修改 `.env` 后必须重启服务。

## 基础服务配置

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `NODE_ENV` | `development` | 运行环境标记。 |
| `APP_NAME` | `ChatGPT Super Local Link Pro` | 服务名称，会出现在配置摘要里。 |
| `PORT` | `2091` | 本地 HTTP 端口，ngrok 要转发到这个端口。 |
| `HOST` | `127.0.0.1` | 监听地址。本地开发建议保持 `127.0.0.1`。 |
| `TRUST_PROXY` | `1` | Express trust proxy。使用 ngrok / 反向代理时建议开启。 |
| `LOG_LEVEL` | `info` | 日志级别：`trace`、`debug`、`info`、`warn`、`error`。 |
| `LOG_DIR` | `./logs` | 日志目录，启动时会自动创建。 |

## MCP 端点配置

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `MCP_PATH` | `/mcp` | Streamable HTTP MCP 入口。ChatGPT 连接器 URL 必须以这个路径结尾。 |
| `ENABLE_LEGACY_SSE` | `1` | 是否启用旧版 SSE 兼容入口。 |
| `SSE_PATH` | `/sse` | 旧版 SSE 连接入口。ChatGPT 新连接器通常不用它。 |
| `SSE_MESSAGES_PATH` | `/messages` | 旧版 SSE 消息入口。 |
| `MCP_STATEFUL_SESSIONS` | `0` | 是否启用有状态 MCP session。ChatGPT 本地连接建议保持 `0`。 |
| `MCP_ENABLE_JSON_RESPONSE` | `1` | Streamable HTTP 是否优先返回 JSON response。 |

ChatGPT 里填写的公网地址格式是：

```text
https://你的公网域名/mcp
```

如果你把 `MCP_PATH` 改成别的路径，例如 `/chatgpt-mcp`，ChatGPT 里也要同步改成：

```text
https://你的公网域名/chatgpt-mcp
```

## 认证和 HTTP 配置

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `AUTH_MODE` | `no-auth` | 认证模式。可选值：`no-auth`、`bearer`。ChatGPT Developer Mode 连接器建议保持 `no-auth`。 |
| `AUTH_TOKEN` | 空 | `AUTH_MODE=bearer` 时使用，长度必须至少 16 个字符。 |
| `CORS_ALLOWED_ORIGINS` | `*` | CORS 来源。多个来源用英文分号 `;` 分隔。开发期可用 `*`。 |
| `HTTP_RATE_LIMIT_WINDOW_MS` | `60000` | 简单速率限制窗口，单位毫秒。`0` 表示关闭速率限制。 |
| `HTTP_RATE_LIMIT_MAX` | `240` | 每个窗口内允许的请求数。`0` 表示关闭速率限制。 |

当前项目没有实现 OAuth。ChatGPT 连接器里不要选 OAuth，应选择：

```text
No Authentication / 无身份验证
```

如果给自己的客户端使用 Bearer token：

```env
AUTH_MODE=bearer
AUTH_TOKEN=至少16位的随机字符串
```

请求时需要带：

```text
Authorization: Bearer 你的AUTH_TOKEN
```

## ROOTS 白名单目录

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `ROOTS` | `./workspace` | 允许访问的本地目录，多个目录用英文分号 `;` 分隔。目录必须存在。 |
| `ALLOW_RELATIVE_PATHS` | `1` | 是否允许相对路径按第一个 ROOT 解析。 |

macOS / Linux 示例：

```env
ROOTS=/Users/me/work/project-a;/Users/me/work/project-b
```

Windows 示例：

```env
ROOTS=D:/work/project-a;D:/work/project-b
```

安全建议：

- 不要把整个磁盘设为 ROOTS。
- 不要把用户主目录设为 ROOTS。
- 不建议把整个 Desktop 设为 ROOTS。
- 最好精确到一个具体项目目录。

## 读取和搜索限制

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `MAX_READ_BYTES` | `262144` | 单文件读取上限，超过后会截断读取。 |
| `MAX_READ_MANY_FILES` | `20` | `read_many_files` 单次最多读取文件数。 |
| `MAX_READ_MANY_TOTAL_BYTES` | `1048576` | `read_many_files` 单次总读取字节上限。 |
| `MAX_SEARCH_FILE_BYTES` | `524288` | `search_files` 搜索时单文件大小上限。 |
| `MAX_SEARCH_FILES` | `2500` | `search_files` 单次最多扫描文件数。 |
| `MAX_SEARCH_RESULTS` | `200` | `search_files` 单次最多返回结果数。 |
| `MAX_SEARCH_RESULT_LINE_CHARS` | `260` | 搜索结果单行预览最大字符数。 |
| `DEFAULT_TREE_DEPTH` | `3` | `directory_tree` 默认目录树深度。 |
| `MAX_TREE_DEPTH` | `8` | `directory_tree` 允许的最大深度。 |
| `MAX_TREE_ENTRIES` | `2500` | `directory_tree` 单次最多返回条目数。 |
| `MAX_PROJECT_OVERVIEW_FILES` | `80` | `project_overview` 单次最多采样文件数。 |

## 写入限制

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `ALLOW_WRITE` | `0` | 是否允许创建目录、创建文件、追加内容。 |
| `ALLOW_OVERWRITE` | `0` | 是否允许修改已有文件。 |
| `DRY_RUN_WRITE` | `0` | 写操作只演练不落盘。首次开启写入建议先设为 `1`。 |
| `BACKUP_BEFORE_OVERWRITE` | `1` | 覆盖、追加已有文件、精确替换前是否备份。 |
| `BACKUP_DIR` | `.super-local-link-backups` | 备份目录，位于对应 ROOT 下。 |
| `MAX_WRITE_BYTES` | `524288` | 单次写入内容上限。 |
| `MAX_REPLACE_OCCURRENCES` | `50` | `replace_in_file` 单次最多替换次数。 |

推荐只读：

```env
ALLOW_WRITE=0
ALLOW_OVERWRITE=0
```

允许新建但不允许改已有文件：

```env
ALLOW_WRITE=1
ALLOW_OVERWRITE=0
```

允许修改已有文件：

```env
ALLOW_WRITE=1
ALLOW_OVERWRITE=1
BACKUP_BEFORE_OVERWRITE=1
```

只演练不落盘：

```env
DRY_RUN_WRITE=1
```

## 排除策略

| 变量 | 说明 |
|---|---|
| `DEFAULT_EXCLUDE_PATTERNS` | 默认安全排除，使用英文分号 `;` 分隔。不建议删除敏感项。 |
| `EXTRA_EXCLUDE_PATTERNS` | 你自己的额外排除规则，使用英文分号 `;` 分隔。 |
| `BLOCKED_EXTENSIONS` | 文件扩展名黑名单，使用英文逗号 `,` 分隔。 |

默认排除策略会跳过：

- `.env`、`.env.*`
- secret、credential、token 相关路径
- 密钥文件，例如 `.pem`、`.key`、`id_rsa`
- `.ssh`、`.aws`、`.azure`、`.gcloud`
- `.git`、`.svn`、`.hg`
- `node_modules`、`dist`、`build`、`.next`、`.nuxt`
- sqlite、db、dump、bak 等数据库或备份文件

## 调试端点

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `ENABLE_DEBUG_ENDPOINTS` | `1` | 是否启用 `/debug/config` 脱敏配置摘要端点。 |

`/debug/config` 不返回 token 或 secret，但生产公网环境仍建议关闭：

```env
ENABLE_DEBUG_ENDPOINTS=0
```
