# 环境变量说明

所有配置都在 `.env`。

## 服务配置

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `PORT` | `2091` | 本地 HTTP 端口 |
| `HOST` | `127.0.0.1` | 监听地址，本地开发建议保持 127.0.0.1 |
| `MCP_PATH` | `/mcp` | ChatGPT 连接器入口 |
| `ENABLE_LEGACY_SSE` | `1` | 是否启用旧版 SSE 兼容入口 |
| `MCP_STATEFUL_SESSIONS` | `0` | 是否启用有状态 MCP session |
| `MCP_ENABLE_JSON_RESPONSE` | `1` | 是否优先返回 JSON response |

## 认证配置

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `AUTH_MODE` | `no-auth` | ChatGPT Developer Mode No Authentication 保持该值 |
| `AUTH_TOKEN` | 空 | `AUTH_MODE=bearer` 时使用 |
| `CORS_ALLOWED_ORIGINS` | `*` | 开发期可用 `*`，生产建议收窄 |

## 白名单目录

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `ROOTS` | `./workspace` | 允许访问的本地目录，多个用 `;` 分隔 |
| `ALLOW_RELATIVE_PATHS` | `1` | 允许相对路径相对第一个 ROOT 解析 |

## 读取限制

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `MAX_READ_BYTES` | `262144` | 单文件读取上限 |
| `MAX_READ_MANY_FILES` | `20` | 批量读取文件数量上限 |
| `MAX_READ_MANY_TOTAL_BYTES` | `1048576` | 批量读取总字节上限 |
| `MAX_SEARCH_FILE_BYTES` | `524288` | 搜索时单文件大小上限 |
| `MAX_SEARCH_FILES` | `2500` | 搜索扫描文件数量上限 |
| `MAX_SEARCH_RESULTS` | `200` | 搜索结果上限 |
| `DEFAULT_TREE_DEPTH` | `3` | 默认目录树深度 |
| `MAX_TREE_DEPTH` | `8` | 目录树最大深度 |
| `MAX_TREE_ENTRIES` | `2500` | 目录树最大返回条目数 |

## 写入限制

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `ALLOW_WRITE` | `0` | 是否允许创建文件/目录 |
| `ALLOW_OVERWRITE` | `0` | 是否允许修改已有文件 |
| `DRY_RUN_WRITE` | `0` | 写操作只演练不落盘 |
| `BACKUP_BEFORE_OVERWRITE` | `1` | 覆盖/替换前备份 |
| `BACKUP_DIR` | `.super-local-link-backups` | 备份目录 |
| `MAX_WRITE_BYTES` | `524288` | 单次写入上限 |
| `MAX_REPLACE_OCCURRENCES` | `50` | 单次精确替换最大次数 |

## 排除策略

| 变量 | 说明 |
|---|---|
| `DEFAULT_EXCLUDE_PATTERNS` | 默认安全排除，不建议删除敏感项 |
| `EXTRA_EXCLUDE_PATTERNS` | 自定义额外排除 |
| `BLOCKED_EXTENSIONS` | 文件扩展名黑名单 |
