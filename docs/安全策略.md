# 安全策略

## 默认只读

`.env` 默认：

```env
ALLOW_WRITE=0
ALLOW_OVERWRITE=0
```

这意味着 ChatGPT 只能读取安全文件，不能创建、追加、替换或覆盖文件。

## ROOTS 白名单

所有路径必须在 `.env` 的 `ROOTS` 里。路径会经过两层检查：

1. 词法路径必须位于 ROOTS 内。
2. `realpath` 后仍然必须位于 ROOTS 内，防止 symlink 逃逸。

## 默认敏感路径排除

默认排除：

- `.env`、`.env.*`
- `*secret*`、`*credential*`、`*token*`
- `*.pem`、`*.key`、`id_rsa`、`id_ed25519`
- `.ssh`、`.aws`、`.azure`、`.gcloud`
- `.git`、`.svn`、`.hg`
- `node_modules`、`dist`、`build`、`.next`、`.nuxt`
- sqlite/db/dump/bak 等数据库或备份文件

## 二进制文件拒绝

读取和搜索会检查文件扩展名、文件大小和二进制特征。二进制文件会被拒绝。

## 写入分级

| 场景 | 所需配置 |
|---|---|
| 创建目录 | `ALLOW_WRITE=1` |
| 创建新文件 | `ALLOW_WRITE=1` |
| 覆盖文件 | `ALLOW_WRITE=1` + `ALLOW_OVERWRITE=1` |
| 精确替换 | `ALLOW_WRITE=1` + `ALLOW_OVERWRITE=1` |
| 只演练不落盘 | `DRY_RUN_WRITE=1` |

## 覆盖前备份

```env
BACKUP_BEFORE_OVERWRITE=1
BACKUP_DIR=.super-local-link-backups
```

替换或覆盖已有文件时，会在 ROOT 下创建备份。

## 不提供的能力

本项目故意不提供：

- 执行 shell 命令
- 删除文件
- 删除目录
- 读取任意磁盘
- 读取浏览器数据
- 读取密钥文件

## 推荐设置

读取项目时：

```env
ALLOW_WRITE=0
ALLOW_OVERWRITE=0
```

让 ChatGPT 修改代码前：

```env
ALLOW_WRITE=1
ALLOW_OVERWRITE=1
DRY_RUN_WRITE=1
```

确认工具调用计划无误后：

```env
DRY_RUN_WRITE=0
```
