# 详细使用说明

## 1. 这是什么

`ChatGPT Super Local Link Pro` 是一个本地运行的 Node.js / TypeScript MCP Server。它把你指定的本地项目目录暴露成一组受控工具，让 ChatGPT 可以读取项目结构、搜索代码、读取文件，并在你明确开启写入后创建或修改文件。

它不是远程虚拟机，也不是 ChatGPT 直接访问硬盘。完整链路是：

```text
ChatGPT
  ↓ HTTPS MCP
ngrok / Cloudflare Tunnel 公网地址
  ↓
本机 Node.js MCP Server
  ↓
.env 中 ROOTS 白名单目录
```

## 2. 环境要求

- Node.js 20.11 或更高版本
- npm
- ngrok 或 Cloudflare Tunnel
- ChatGPT 中开启 Developer Mode

Windows 用户建议使用 PowerShell。

## 3. 安装

解压项目后进入目录：

```powershell
cd chatgpt-super-local-link-pro
npm install
npm run doctor
```

如果 `doctor` 成功，会输出脱敏后的配置摘要。

## 4. 配置 ROOTS

编辑 `.env`：

```env
ROOTS=D:/work/JiaDianAI;D:/mcp-work/harmonyos-libretro-emulator
```

注意：

- 多个目录用英文分号 `;` 分隔。
- Windows 路径建议写成 `D:/work/project`，不要写成 `D:\work\project`。
- 不要把 `C:/`、`D:/` 整个盘符作为 ROOTS。
- 不要把用户主目录整体作为 ROOTS。

## 5. 启动本地服务

开发模式：

```powershell
npm run dev
```

生产模式：

```powershell
npm run build
npm run start
```

默认本地地址：

```text
http://127.0.0.1:2091/mcp
http://127.0.0.1:2091/health
```

## 6. 暴露 HTTPS 地址

ChatGPT 连接器需要公网 HTTPS 地址。本地开发可以使用 ngrok：

```powershell
ngrok http 2091
```

看到类似：

```text
Forwarding  https://abc123.ngrok.app -> http://localhost:2091
```

那么连接器 URL 填：

```text
https://abc123.ngrok.app/mcp
```

## 7. 在 ChatGPT 中添加连接器

1. 打开 ChatGPT 设置。
2. 进入 Apps & Connectors / Connectors。
3. 开启 Developer Mode。
4. 点击 Create。
5. 填写：
   - Name：超级本地链接 Pro
   - Description：安全读取和可选编辑本机白名单项目目录
   - Authentication：No Authentication
   - Connector URL：`https://你的域名/mcp`
6. 创建成功后应能看到工具列表。

## 8. 第一次对话建议

```text
使用“超级本地链接 Pro”读取我的项目。先调用 list_allowed_roots，再对 D:/work/JiaDianAI 调用 project_overview 和 directory_tree。不要读取 .env、密钥、数据库、node_modules、dist、.git。第一轮只输出项目结构、关键文件、技术栈判断和建议下一步读取哪些文件，不做任何写入。
```

## 9. 写入模式

默认只读：

```env
ALLOW_WRITE=0
ALLOW_OVERWRITE=0
```

允许创建新文件/目录，但不允许改已有文件：

```env
ALLOW_WRITE=1
ALLOW_OVERWRITE=0
```

允许修改已有文件：

```env
ALLOW_WRITE=1
ALLOW_OVERWRITE=1
BACKUP_BEFORE_OVERWRITE=1
```

建议首次开启写入时先演练：

```env
ALLOW_WRITE=1
ALLOW_OVERWRITE=1
DRY_RUN_WRITE=1
```

确认工具返回符合预期后，再改：

```env
DRY_RUN_WRITE=0
```

## 10. 推荐工作流

读取阶段：

```text
先调用 list_allowed_roots、project_overview、directory_tree。重点查看 AGENTS.md、README.md、package.json、src 入口、docs、scripts。不要读取 .env、secrets、数据库、构建产物和依赖目录。
```

分析阶段：

```text
根据目录结构和关键文件，输出技术栈判断、模块划分、可能入口、构建脚本、下一轮建议读取文件。不要写入。
```

修改阶段：

```text
在修改前先说明计划。优先使用 replace_in_file 做小范围精确替换。不要覆盖整文件，除非我明确要求。
```

## 11. 关闭服务

终端里按 `Ctrl+C`。
