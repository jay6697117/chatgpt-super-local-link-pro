# 工具清单

## list_allowed_roots

用途：查看服务器允许访问哪些本地目录、当前认证方式、写入开关和安全限制。

建议：每个新对话先调用它。

## project_overview

用途：快速识别项目关键文件、技术栈线索、package.json 摘要和推荐下一步读取文件。

适合第一次读取项目。

## directory_tree

用途：读取目录结构。

参数：

- `path`：目录路径。
- `depth`：目录深度。
- `maxEntries`：最大条目数。
- `excludePatterns`：额外排除规则。

## file_stat

用途：读取文件或目录元信息。

返回类型、大小、创建/修改时间。

## read_file

用途：读取单个 UTF-8 文本文件。

限制：

- 不读取二进制文件。
- 不读取敏感路径。
- 大文件会截断。

## read_many_files

用途：一次读取多个文本文件。

适合读取 `AGENTS.md`、`README.md`、`package.json`、入口文件等。

## search_files

用途：搜索目录下文本内容。

常用参数：

```json
{
  "path": "D:/work/project",
  "query": "OnlyOffice",
  "mode": "literal",
  "includeGlob": "**/*.{ts,vue,md}"
}
```

## create_directory

用途：创建目录。

需要：

```env
ALLOW_WRITE=1
```

## write_file

用途：创建或覆盖文件。

创建新文件需要：

```env
ALLOW_WRITE=1
```

覆盖已有文件需要：

```env
ALLOW_WRITE=1
ALLOW_OVERWRITE=1
```

## append_file

用途：追加内容到文件末尾。

如果文件已存在，需要 `ALLOW_OVERWRITE=1`。

## replace_in_file

用途：对已有文件做精确文本替换。

适合小范围代码修改。

需要：

```env
ALLOW_WRITE=1
ALLOW_OVERWRITE=1
```

默认会在覆盖前备份。

## server_config_summary

用途：查看脱敏配置摘要，不返回 token 或 secrets。
